An end-to-end academic study of neural architectures across tabular data, computer vision, and natural-language sequences. The project pairs theory with reproducible PyTorch experiments, evaluation artifacts, notebooks, and a complete scientific report.

## What is covered

| Track | Task | Architectures | Data |
|---|---|---|---|
| Tabular learning | Binary classification | Custom and sequential MLPs | Breast Cancer Wisconsin |
| Computer vision | Image classification | MLP baseline and LeNet-style CNN variants | Fashion-MNIST / scikit-learn Digits |
| Sequence modelling | Text classification | RNN, LSTM, GRU | 20 Newsgroups / local fallback corpus |
| Sequence generation | Encoder-decoder generation | GRU Seq2Seq | Compact bilingual sentence pairs |

## Repository map

## Quick start

```bash
python -m venv .venv
source .venv/bin/activate       # Linux/macOS
# .venv\Scripts\activate        # Windows
pip install -r requirements.txt
```

Run an experiment:

```bash
python part1_mlp/train_mlp.py --epochs 30 --batch-size 32
python part2_cnn/train_cnn.py --dataset digits --epochs 12 --batch-size 64
python part3_rnn/train_rnn_text.py --epochs 6 --batch-size 32
python part3_rnn/tiny_seq2seq.py --epochs 300
```

Each script writes its metrics and visualizations under `results/`.

## Notebooks and report

Install the notebook dependencies and launch Jupyter:

```bash
pip install -r requirements-jupyter.txt
jupyter notebook
```

The repository includes guided notebooks, a consolidated executable notebook, a polished standalone HTML report in `docs/`, and the complete PDF report in `report/`.

## Reproducibility

- Random seeds are centralized in `src/common.py`.
- CPU-friendly defaults keep the experiments practical on a 16 GB laptop.
- Results are generated by the scripts; reported metrics are not manually invented.
- Dataset fallbacks allow core experiments to run when downloads are unavailable.
